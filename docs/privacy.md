# Privacy: Windows capture preview

This build stores meeting metadata, typed notes, fictional fixtures, and settings in a local SQLite database. Export uses a folder explicitly chosen through the native picker. Windows desktop capture code writes separate microphone/system WAVs and timing JSONL locally under the app-data `audio/<meeting ID>/` directory. Capture qualification has not passed; macOS capture is unsupported. Simulation opens no audio devices. The local model selector reads installed-model metadata only from `http://127.0.0.1:11434/api/tags` when you refresh or save a choice. Requests have bounded time/body size, bypass proxies, and refuse redirects. Models reported as remote/cloud are excluded; no prompt, audio, or notes are sent. No Ollama/model installation happens automatically. Merge Gateway support is limited to credential storage and model discovery: when you press Connect / refresh or save a Merge model, Rust sends one authenticated `GET https://api-gateway.merge.dev/v1/models` (paginated, bounded, redirects refused) carrying only your API key. No notes, transcripts, or audio are sent, and no summary or inference request exists. The key is read from the `OPENMEET_LLM_API_KEY` environment variable by Rust on explicit import and stored in the OS keychain; it is never sent to the webview, SQLite, or logs, but the environment variable itself stays in your shell or profile until you remove it. **Local speech-to-text.** Only when you press Download in Settings, the app fetches a pinned whisper.cpp Windows build (release b5454, github.com), the Whisper model selected in Settings (base, small or large-v3-turbo) and the Silero VAD model (huggingface.co), rejecting anything whose size or SHA-256 differs. Switching models never deletes one already downloaded. The chosen language and optional vocabulary hint are stored in SQLite and passed only to the local engine. Cancelling a transcription stops the engine and keeps the previous transcript. Finalized WAV tracks are then transcribed by that engine as a local subprocess; audio is never uploaded. Transcript text is stored unencrypted in the local SQLite database. The engine receives file paths and model paths only; transcript text is not logged.

**Summaries.** Pressing Enhance notes shows what will be sent; only after you confirm does the backend POST your notes and the transcript text (never audio) to `https://api-gateway.merge.dev/v1/chat/completions` with the model you saved. Each send needs fresh confirmation, nothing is generated automatically, and Merge and the model provider's own terms govern that text once sent. The result is stored with its provider and model and never replaces your notes; earlier summaries are kept. Very long meetings are refused locally rather than truncated. There is no telemetry or updater.

For playback, the webview can load files under the app-data `audio/` folder through Tauri's asset protocol; its scope is limited to that folder. Otherwise the packaged frontend has no permission to read arbitrary files, register shortcuts, open dialogs directly, or call arbitrary network services. Merge model discovery and summaries are performed by Rust, not by the webview. Rust exposes specific operations; its folder picker is the only way to change the export destination. Development mode also uses Vite's localhost server.

The database, audio, timing files, and exported Markdown are **not encrypted**. Device administrators, OS backups, and sync software can access them. Choosing a cloud-synced folder can upload exports even though OpenMeet makes no upload request. There is no retention cleanup or in-app deletion UI yet; original and partial audio files are retained even after capture failures. Close the app before manually removing its app-data directory; exported files must be removed separately.

Autosave waits 400 ms and serializes writes. Stop requests capture shutdown without waiting for note saving; failed drafts remain on screen. Graceful close flushes notes and refuses to quit on save failure. A forced process termination or power loss can lose edits not yet saved. Use synthetic data during this unvalidated preview.

Real recording requires participant consent acknowledgement and OS/device access. System capture can include unrelated application audio. Before qualification or cloud processing ships, validate pause privacy and local-only egress, and extend this policy for model downloads and provider disclosure. Those checks have not passed.
